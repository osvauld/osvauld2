## 1. Overlay — catcher + dismiss  (LOAD-BEARING — gates M2 combobox)
Theory: append a full-window invisible **catcher** rect *under* the panel and *over* main
content. An outside-click hits the catcher → emits a **dismiss message**; the app flips
its `open` bool, and next frame `view()` omits the overlay. The runtime stores no open
state (derived-view model). The catcher is also what makes the flavors one mechanism:
none = tooltip (click-through), invisible = popover, dim scrim = modal.
- [x] `Overlay<M> { panel, dismiss: Option<M> }` — `Some` = catcher, `None` = tooltip
- [x] catcher: full-viewport `col().w(vp.0).h(vp.1).on_click(dismiss)`, own taffy tree
- [x] layer order: catcher emitted before panel → `[main…, catcher, panel]`, hit-first ok
- [x] dismiss is an app **message** (todo.rs: `ToggleOverlay` for open + dismiss)
- [x] Proven: conditional `.overlay(..)` on `open_menu`; click-away closes
- [ ] modal scrim fill (cut line — defer)

## 4. Animation system — infrastructure
Theory: animated hover flips hover from **stateless** (derived `pointer ∩ rect` each
frame) to **stateful** — you must retain *how long since hover started*. Keep progress
(0→1) per animated id in the `Store`, tick it via the timer wheel each frame while any
animation is in flight.
- [ ] `EventLoopProxy<UserEvent>` wakeup path (from §2.7)
- [ ] timer wheel: per-frame tick advancing progress by dt
- [ ] transition state in `Store` keyed by id (reuses the `(Id, TypeId)` store)
- [ ] request-redraw while any animation is running (replaces all-or-nothing `animating()`)
